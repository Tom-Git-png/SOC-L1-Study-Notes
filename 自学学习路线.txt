阶段 0：前置基础（必学，1‑2 个月）
没这部分直接学渗透，命令、代码全看不懂，非常容易放弃

1. 计算机网络基础（重中之重）
学习内容：
- OSI 七层模型、TCP/IP 四层模型
- IP、子网掩码、网关、DNS、HTTP/HTTPS 协议
- 请求头、响应头、Cookie、Session、状态码、GET/POST
- 端口、常见服务：80、443、22、3306、3389
推荐资料：图解 HTTP、B 站计算机网络课程

2.Linux 基础（渗透必备，优先学 Ubuntu / CentOS）
必练命令：
cd ls pwd mkdir rm cp mv cat grep chmod ps netstat ifconfig ssh
学会：文件权限、进程查看、服务启动关闭、远程 ssh 连接、简单 shell 脚本

3. 编程语言基础（不用精通，看得懂代码即可）
1）Python：最核心，基础语法、循环、条件、函数、requests 库（发 http 请求）
2）HTML+CSS+JavaScript：看懂网页源码，前端漏洞基础
3）SQL 基础：增删改查 select insert delete，为 SQL 注入打基础
不需要学高深算法，够用就行


阶段 1：Web 安全入门（渗透核心，2‑3 个月）
这是就业最多的方向，Web 渗透测试工程师
核心漏洞逐个吃透（原理 + 复现 + 防御）
1. SQL 注入
2. XSS 跨站脚本
3. CSRF 跨站请求伪造
4. 文件上传漏洞
5. 文件包含漏洞
6. 命令执行漏洞
7. SSRF
8. 逻辑漏洞（越权、密码重置、支付漏洞）
9. 反序列化

必学工具
- Burp Suite：抓包改包神器（Web 渗透第一工具）
- Sqlmap：自动 SQL 注入工具
- DVWA、Pikachu (皮卡丘靶场)：本地练习漏洞
- 浏览器插件：HackBar、Wappalyzer
学习方法：**先懂漏洞原理 → 靶场复现 → 手写 payload → 了解如何防御**


阶段 2：进阶渗透 & 内网安全（2‑3 个月）
Web 进阶
- 代码审计基础（PHP 代码看漏洞）
- CMS 漏洞：Discuz、Wordpress、ThinkPHP 漏洞
- 漏洞平台：CNVD、CVE 漏洞复现

内网渗透（入职必备技能）
- Windows 基础：注册表、组策略、常见命令 cmd、powershell
- 信息收集、端口扫描：Nmap
- 权限提升、横向移动、域环境基础
- 工具：Nmap、Hydra (暴力破解)、MSF (Metasploit)

CTF 练手平台（提升实战）
- ctf.show、Bugku、OverTheWire(Bandit、Natas)


阶段 3：安全工程化 & 就业方向选择（1‑2 个月）
可选岗位路线（三选一深耕）
1. **渗透测试工程师（最推荐新手）**：挖漏洞、红蓝对抗、等保测评
2. **安全运营工程师**：告警分析、防火墙、日志、应急响应，门槛偏低好入行
3. **开发安全 / 代码审计**：深挖代码、SDL 安全开发
4. **等保测评工程师**：偏合规，技术难度低

必备实战项目（写进简历）
1. 靶场完整渗透报告（皮卡丘、DVWA）
2. 开源 CMS 漏洞复现文档
3. 自己搭建 VPS，复现漏洞，写 markdown 复盘
**红线！禁止**：未经授权扫描、测试外网网站，属于违法行为！！！只能在本地靶场、授权靶场练习


阶段 4：证书推荐（求职加分项）
入门‑中级（国内就业友好）
1. HCIA‑Security / HCIP‑Security（华为安全）
2. CISSP（偏管理，工作后考）
3. CISP‑PTE（国内渗透热门证书，企业认可度高）
不建议一开始就报高价培训班，先自学基础再决定

国际证书（高薪进阶）
OSCP（渗透测试含金量天花板，强烈推荐后期备考）


阶段 5：投递实习 / 工作 + 长期成长
求职渠道
- 补天、CNVD 漏洞平台提交漏洞，攒漏洞证明（简历硬核加分）
- 安全客、先知社区、FreeBuf 看行业文章
- 投递：安全实习生、渗透测试助理、安全运营

每日长期习惯
1. 看安全公众号、安全社区新鲜漏洞
2. 复现 1 个 CVE 漏洞
3. 坚持写技术笔记

总周期参考
- 自学全职：6‑8 个月可达到初级网安工程师水平
- 业余晚上学习：10‑14 个月

免费自学资源清单
1. B 站：Web 安全、皮卡丘靶场全套教程
2. 靶场：DVWA、Pikachu、WebGoat、ctf.show
3. 社区：FreeBuf、先知社区、安全客
