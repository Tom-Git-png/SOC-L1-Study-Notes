阶段 0 | 前期准备（1 周）
1. 虚拟机环境安装 VirtualBox / VMware
2. 搭建一台 Windows10 虚拟机 + Kali（仅用来做流量分析，**不用打靶拿 shell**）
3. 注册 TryHackMe 账号，核心学习靶场
4. Github 账号，存放你的分析报告作品集（求职简历加分项）


阶段1｜基础地基（2 个月，重中之重）
SOC 和渗透学习唯一重合的部分，全部必须学完

1、计算机网络（SOC 第一核心，约 4‑5 周）
学习清单
- OSI 七层模型、TCP/IP 四层模型
- IP 地址、子网掩码、网关、路由
- TCP 协议：三次握手、四次挥手、滑动窗口、端口
- UDP、ICMP、ARP、DNS、DHCP、SMB、RDP、SSH、FTP 协议原理
- HTTP/HTTPS 完整流程，请求头、响应头、状态码、Cookie、Session
- TLS/SSL 加密基础
实操练习
- Wireshark 抓包：抓取 TCP 三次握手，HTTP 请求报文
补充：
靶场：TryHackMe → Pre‑Security 路径网络模块
这些都是真实攻击流量、入侵日志，用来写你的 GitHub 作品集报告
1）. Boss‑of‑the‑SOC (BOTS) Splunk 日志数据集
模拟企业完整入侵场景，练习 SIEM 日志检索研判，非常适合做项目作品CSDN博...
2）. Malware‑Traffic‑[Analysis.net](https://link.wtturl.cn/?target=https%3A%2F%2FAnalysis.net&scene=im&aid=582478&lang=zh)
大量真实木马 pcap 流量包，练习 Wireshark 恶意流量分析，免费下载，蓝队必练素材
3）. Security‑Datasets
开源攻击日志、流量数据包集合

2、操作系统安全（Windows + Linux，3‑4 周）
Windows（SOC 研判最高频系统，优先学）
- 文件目录结构、进程、服务、注册表
- 用户、组、权限；远程桌面 RDP
- Windows 安全事件日志（重中之重）
熟记关键事件 ID：
  - 4624：登录成功
  - 4625：登录失败（暴力破解告警来源）
  - 4688：新建进程
  - 4698：创建计划任务（恶意持久化）
  - 7045：安装新服务
- 任务管理器、资源监视器、Sysmon 日志
Linux（基础够用即可，不用深度运维）
基础命令：`ls、cd、cat、ps、netstat、ss、grep、tail、chmod`
查看系统日志 `/var/log`，识别异常登录

3、Python 极简基础（2 周，够用即可）
只学：变量、字符串、文件读取、简单循环。
不用学爬虫、漏洞脚本开发；SOC 日常用来解析日志。
结束验收标准：
给一份 pcap 流量包，可以看出 TCP 会话，看懂一条 HTTP 请求。


阶段2｜安全基础 + 攻击原理（1.5 个月）
防守视角！看懂攻击现象、告警特征，不练漏洞利用

1. Web 安全基础（OWASP Top10）
SQL 注入、XSS 跨站、文件上传、目录遍历、命令执行
学习目标：知道攻击长什么样、日志会留下什么痕迹
禁止深挖：Payload 构造、绕过 WAF、拿 Shell 技巧

2. 恶意代码基础
病毒、木马、勒索病毒、挖矿程序、远控 C2、钓鱼邮件

3. 安全基础概念
防火墙、WAF、EDR、IDS/IPS、SIEM、沙箱、威胁情报、IOC 指标（IP、域名、MD5 哈希）

4. 杀伤链 Cyber‑Kill‑Chain + **MITRE ATT&CK 框架（SOC 研判思维核心）**
初始访问→执行→持久化→权限提升→横向移动→数据渗出
实操靶场：TryHackMe SOC‑Level‑1 前半段模块TryHackMe


阶段3｜SOC 岗位核心硬核技能（2.5 个月｜求职最核心板块）
这一块就是你入职之后每天干的活

模块 1：告警研判（Alert Triage）L1 分析师首要工作
区分：误报 / 可疑告警 / 真实安全事件
SOC 工作流：收到告警 → 调取日志流量 → 查询威胁情报 → 给出研判结论

模块 2：日志分析
- Windows 事件日志深度分析
- Linux 系统日志、Web 服务器访问日志（Nginx/Apache）
- 从日志中识别：暴力破解、Web 攻击、异常进程、横向移动痕迹

模块 3：流量分析（Wireshark 进阶）
从 pcap 流量包识别：端口扫描、远控 C2 心跳流量、挖矿流量、DNS 隧道

模块 4：钓鱼邮件分析
解析邮件头、识别恶意附件、钓鱼 IOC 提取

模块 5：SIEM 平台实操
- Splunk 免费版：学习 SPL 搜索语句，检索日志，查看告警
- TryHackMe 内置 SOC 模拟器，练习告警研判实操任务TryHackMe

模块 6：应急响应基础流程
1. 隔离受害主机
2. 封禁恶意 IP
3. 溯源攻击路径
4. 撰写安全事件分析报告（求职必练！）
 主线靶场：TryHackMe SOC‑Level‑1 完整路径（必刷），最适合国内新人入门 SOC 的蓝队路线。


阶段4 |  额外可选练习（攻防世界，有限刷题）
只刷这两类，其余 Crypto、Pwn、逆向直接跳过

1. Misc 杂项 —— 流量分析包、日志分析题
2. Web 入门题（5‑8 题即可，用来看懂 Web 攻击）


阶段5｜实战作品集项目（1‑1.5 个月｜简历加分核心）
没有真实工作经验，就用项目作品集弥补，放到 GitHub 上。推荐 3 个必做项目：

项目 1：流量分析报告
给一份恶意 pcap 包，完整分析攻击全过程，输出研判报告，标注 ATT&CK 战术

项目 2：Windows 入侵日志溯源
一份入侵 Windows 日志，还原攻击者登录、植入后门、持久化操作全过程

项目 3：SIEM 告警分析模拟
使用 Splunk 查询日志，模拟 SOC 分析师完成告警研判，生成事件报告
